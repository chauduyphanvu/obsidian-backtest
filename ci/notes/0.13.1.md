Changes from the automated review of the Community plugins directory. The backtests and their figures are the same as in 0.13.0.

- **Fewer review warnings.** The review of 0.13.0 found 319 items. Most were about the code: numbers with more digits than a computer keeps, type checks with no effect, data from Yahoo and Binance with no type, and timers and elements that did not use the functions Obsidian gives for windows that you move out of the main window. These are fixed. The numbers that the calculations use did not change.
- **Signed release files.** GitHub now records where each file of a release comes from. A workflow on GitHub builds the release again from its tag, compares each file with the file in the release, and signs the files only when they are the same. To check a file that you downloaded: `gh attestation verify main.js --repo chauduyphanvu/obsidian-backtest`.
- **No "dynamic code" note.** The review said that the plugin may run code that it makes as it runs. It does not. The review saw a function with the name `eval`, which calculates the values of a rule. That function now has another name.
