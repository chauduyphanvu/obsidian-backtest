Fixes from an audit of how the plugin keeps track of runs, each tried before and after in a running Obsidian:

- **Refresh really refreshes.** "Run again" under a `backtests` block and "Refresh prices" in the orders window, pressed while another round was running (or while the status bar's check ran), could leave strategies on the prices from before. They now reuse no result worked out from prices fetched before they began.
- **Today's orders on fresh prices.** A result was kept for the "Keep saved prices for" time from when it was worked out, so today's orders could rest on prices nearly twice that old and miss the latest close. A result now runs again once the prices it was worked out from are older than that setting. A result made offline, on saved prices, is still kept, without trying the download at every drawing.
- **Luck checks.** "Run checks again" waits while "Shuffle again" runs, so Stop always stops what is running.
- **Status bar.** After "Couldn't check orders" because every strategy failed (offline with no saved prices), the count tries again 10 minutes later instead of after the "Keep saved prices for" time.
- **Strategy preview.** After "Try again" while a newer edit was waiting, undoing back to the retried text now runs it.
- **Background runs.** One background worker that is slow to start no longer sends every run to the foreground for the rest of the session; a new worker is tried with the next run.
- A block that was drawn again or went away while its result was coming back no longer draws, and a "prices ready" answer worked out while a price file was saved is no longer kept.

Results do not change for a strategy run on fresh prices.
