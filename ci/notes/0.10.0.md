All text that the plugin shows is now in Simplified Technical English (ASD-STE100): short sentences, one meaning for each word, and no contractions. Trading terms stay. The figures and the backtests are the same as in 0.9.2.

- **Results.** The verdict now reads "7.2% a year, compared with 10.6% for buy and hold. But its worst drawdown was smaller: 24%, compared with 55%." The result uses "worst drawdown" in all places, and "better than" or "worse than" to compare with the benchmark.
- **Messages.** Errors, warnings, quick fixes, editor help, explanations, luck checks, the sweep, orders, accounts, forward tests, the command line and the MCP server use the same plain style.
- **New names.**
  - Settings: "Start capital", "Price source for tickers without a prefix", "Use Tiingo when Yahoo is not available", "Result view", "Find orders when Obsidian starts", "Find tickers while you type".
  - Commands: "Write a strategy from a description", "Delete saved prices", "Correct the problem at the cursor". The command IDs did not change, thus your hotkeys continue to work.
  - "Market falls" is now "Market drawdowns". The trade button is "Show the reasons for this trade".
- **Forward tests.** A new forward test writes a different comment above its pinned settings. Thus its check code is different. Forward tests that you started before are not affected.
- The prompt that the plugin sends to a language model did not change.
