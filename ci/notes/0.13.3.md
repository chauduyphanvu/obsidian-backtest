Two fixes for the automated review of 0.13.2 in the Community plugins directory. The backtests and their figures are the same as in 0.13.2.

- **Settings.** When you change the provider of the strategy writer, the plugin now updates the descriptions and examples of the server address, model and API key in place. Before, Obsidian 1.13 and later drew the whole tab again, with a call that the review reports as newer than the oldest Obsidian version that the plugin supports. Settings search finds these rows as before.
- **Editor.** The hover card's helper no longer names `globalThis`. The card is the same.

The review warnings that remain are about the command line, which does not run in Obsidian.
