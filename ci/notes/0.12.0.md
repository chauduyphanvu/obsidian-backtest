Sixteen changes that make a strategy easier to write, read and act on. The backtests are the same as in 0.11.0.

- **Clearer problems.** Six messages now say what is wrong, most with a button that corrects it: `crosses over` ("Change to crosses above"), a parameter outside its range ("Change to 300" or "Change the range to 100..400"), a blank line inside a rule, a `csv:` path with a space, a date with slashes ("Change to 2015-01-01") and a percentage above its maximum. When two corrections are equally near, both show: `sam` offers "Change to sma" and "Change to sum". Near the top of the editor, the help opens under the line, so it does not cover the tabs.
- **Make a number a parameter.** Move the pointer to a number such as the 200 in `sma(200)` and click "Make 200 a parameter". The plugin adds `sma_n = 200 in 100..400 step 20`, uses it in each place the same call is written, and the block gets a slider. There is also a command, and "Try other values" offers the same for a block with no parameters.
- **What each figure means.** Click a figure's name, such as "Sharpe ratio", to read what it is and how the plugin calculates it.
- **Try other values.** The tiles say which period their number comes from ("Chosen before 2018-01-01, result from 2018-01-01"). The heatmap's colours show better or worse than the values in the note, not above or below 0.
- **Charts by keyboard.** Select a chart and use the arrow keys to read it bar by bar, Shift and an arrow for a month (or a year), Home and End, and Escape to go back to the last bar.
- **Copy.** "Copy as Markdown" in the menu puts the result on the clipboard, ready to paste into a note. The panel of the status line has "Copy" for the order alone.
- **Old prices.** When the prices of a result are old, the status line says so in amber ("Prices end on 2026-11-05. They can be old. Click to load new prices."), and a folded result shows "Old prices".
- **When a backtest does not run.** The card gives the next step: "Change to BRK-B" for a ticker that the source does not know, "Open settings" for an API key, "Use a CSV file" for a file that is not there. Today's orders and the `backtests` table have the same buttons.
- **Loading.** The card counts the tickers ("Prices: 3 of 7.") and names one that is slow. CSV files are read in the background, so a large file does not stop Obsidian (a 62 MB file: about 0.09 s of the window's time, not 0.9 s). A file over 100 MB is refused with its size.
- **Go to the block.** A strategy clicked in Today's orders, the `backtests` table or a forward test opens its note at that block, with the result open.
- **New strategy note.** A new command, also with no note open: select a starter strategy and the plugin makes a note for it. Empty windows have the same button.
- **Today's orders in the sidebar.** "Keep in the sidebar" (or the command) keeps the list open while you work. It shows the time of the last check and uses the status bar's check, so the prices load once.
- **Commands for a note.** "Refresh all strategies in this note", "Fold all results in this note" and "Open all results in this note", and for the strategy at the cursor: refresh, keep as a note, start a forward test. You can give each one a hotkey.
- **Rename a strategy.** "Rename the strategy at the cursor" changes the name and keeps the record of tries (so "Was it luck?" still counts them) and the links to it in `compare`, `account` and forward-test notes. If you change the name line yourself, the result offers the same move.
- **Command line and MCP server.** `check` shows the corrections, `check --json` and `check_strategy` give each one as an edit, and `check --fix` writes the ones that have no alternative. `explain` reads phrases such as `for 3 bars`.
